Build Sistem

Cara Kerja Sistem

01

Input Profil

Anda mengisi tingkat penguasaan keterampilan (skala 1–5), minat industri, latar belakang pendidikan, dan preferensi kerja.

02

Vektorisasi Data

Sistem mengonversi seluruh data profil Anda menjadi nilai vektor multidimensional yang merepresentasikan kompetensi Anda.

03

Cosine Similarity

Algoritma menghitung kemiripan sudut (kedekatan nilai) antara vektor kompetensi Anda dengan vektor kualifikasi ideal tiap profesi.

04

Rekomendasi Terurut

Pekerjaan dengan skor tertinggi diranking teratas dan disajikan lengkap dengan analisis kesenjangan kemampuan (skill gap).

Teknologi Core

Algoritma AI

Core Engine

Cosine similarity digunakan untuk mengukur kemiripan antara vektor profil pengguna dan profil karier ideal. Semakin tinggi skornya, semakin relevan rekomendasinya.

Cosine Similarity TF-IDF Vector Space

Processing Layer

Formula Cosine Similarity

Formula Matematika
cos(θ) = A · B
───────────────
‖A‖ × ‖B‖

A = vektor profil pengguna  |  B = vektor profil opsi karier
Nilai output berkisar 0 (tidak cocok) hingga 1 (sangat selaras).

Interpretasi Skor Vektor
≥85%
Sangat Cocok

Kompetensi Anda sangat selaras — jalur karier ini direkomendasikan utama

70–84%
Cukup Cocok

Perlu optimasi di beberapa keahlian untuk memaksimalkan potensi sukses

<70%
Kurang Cocok

Kesenjangan parameter signifikan — butuh pelatihan fondasi tambahan

Pertanyaan Sering Diajukan

Apakah data profil saya aman?
Ya. Seluruh data profil Anda disimpan secara lokal di browser menggunakan localStorage dan tidak dikirim ke server cloud pihak ketiga manapun demi menjaga privasi penuh pengguna.
Seberapa akurat rekomendasi karier yang diberikan?
Akurasi kalkulasi bergantung pada kejujuran input tingkat keahlian Anda. Dalam pengujian internal, sistem algoritma kami mencapai tingkat akurasi kecocokan hingga 92% berdasarkan standar pemetaan industri.
Apakah sistem ini gratis selamanya?
Ya, seluruh fitur pemetaan kompetensi, analisis skill gap, dan rekomendasi jalur belajar di CareerPath dapat diakses sepenuhnya tanpa biaya.
